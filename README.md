## Ритм

Мой первый проект — ежедневник в Telegram. Задачи с повторениями и временем начала и окончания, календарь, заметки, загрузка недели и напоминания в личный чат.

Например, работу каждый понедельник с 15:00 до 17:00 достаточно добавить один раз. Отдельный день можно изменить, сохранив остальные повторения.

[Попробовать бота](https://t.me/serritmbot) · [Коротко о проекте](https://github.com/1eoBrav0/ser-ritm/blob/main/docs/project.md) · [Код и запуск](https://github.com/1eoBrav0/ser-ritm)

Сервер — Python, интерфейс — HTML/CSS/JavaScript. Локально используется SQLite, на сервере — PostgreSQL. Есть автоматические проверки в GitHub Actions. Бот работает без моего компьютера; после простоя открытие иногда занимает около минуты.

На этом проекте разбираюсь в работе интерфейса с сервером, хранении данных, повторениях и запуске приложения на хостинге.
