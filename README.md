## Ритм

Мой первый проект — ежедневник в Telegram. В нём есть календарь, задачи с повторениями, заметки и график загрузки недели. Например, можно один раз поставить работу на каждый понедельник с 15:00 до 17:00.

[Открыть бота](https://t.me/serritmbot) · [Код и инструкция запуска](https://github.com/1eoBrav0/ser-ritm)

Бот сейчас переезжает на постоянный сервер. Локальную версию уже можно запустить из репозитория.
